# Introduction

Juki2D is a project I am working on for fun, the goal is to make a 2D game engine that lets people create any 2D game of their choice. It also serves as a way for me to learn more about C++ and engine development in general.

Built with C++20, SFML 3 and CMake on Visual Studio.

**Implemented as of October 22, 2026:**
- Application: Window Management, Event Handling, Timestep Updates, Rendering Hooks
- Collisions: AA Rectangle Overlaps, Collision-side Queries, Swept AABB
- Movement: Sweep and Slide
- Body2D: Bounds, Velocity, Gravity, States, Collision Response
- Static Library: Juki2D builds separately from Sandbox.exe
- Sandbox: Test game (platformer) demonstrating engine implementations.

## Disclaimer

Juki2D is an early learning project, of course it will not be perfect and most probably not as optimal. Many features are a WIP or yet to be planned out.
